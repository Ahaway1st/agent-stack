# brief-analysis

## 分析动作
1. **拆解 brief**：一句话主题、目标受众、发布场景（决定画幅与时长）、语气/风格、必须传达的信息点（逐条列）、明确不要的东西。
2. **看参考素材**：参考视频要拆到可执行层——镜头节奏、画面构成、字幕样式、音乐类型、转场习惯；只说“高级感”不算分析结论。参考图记录主体、配色、构图。
3. **盘点素材**：已有素材逐项登记（文件、内容、可用片段）；缺口列清单：缺哪类素材、用生成还是实拍/现成、谁来提供。
4. **确认约束**：生成调用的次数/成本上限、交付格式（分辨率、帧率、时长、文件大小）、版权与肖像限制（真人照片不可直接动画化等工具硬限制要在此阶段挑明，不到生成阶段才说）。

## 产出：制作单
    主题 / 受众 / 画幅与时长 / 风格关键词（≤5个，每个能指到参考依据）
    信息点清单（逐条） / 分幕粗纲 / 素材清单与缺口 / 约束与禁区 / 待用户确认项

## 纪律
- 制作单经用户确认才进入 storyboard-prompt；用户改方向时先改制作单，后续产物跟着改，不口头漂移。
- 分析不出的项写“未定”并给选项，不用默认值 silently 填上——尤其画幅、时长和风格，这三项错了全片返工。
