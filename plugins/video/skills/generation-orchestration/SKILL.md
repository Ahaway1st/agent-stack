# generation-orchestration

## 编排流程
1. **先锁资产**：角色锚点图、风格参考、配音/音乐素材先行生成或确认，登记为资产表（名称、文件、版本）。后续所有镜头引用资产表，不临时另造。
2. **排顺序**：先生成风险最高的镜头（主角特写、复杂运动）验证路线可行，再批量推进其余镜头。路线不通时早失败，成本最低。
3. **逐镜登记**：每镜记录用的提示词版本、工具/模型、参数、输出文件、是否通过自检。没有登记的素材不进入后期。
4. **自检关口**：每镜按分镜表核对——主体对不对、角色漂没漂、时长够不够、声音齐不齐。不合格重生成该镜，不将就。
5. **重试纪律**：同一镜失败 2 次，停下来分析原因（提示词/资产/工具限制）并换路线或报告用户，不无脑连重试——重试次数计入 cost-visibility 账本。

## 硬限制（提前挑明，不试错浪费调用）
- 真人照片不能直接动画化为视频；要用其形象，先经用户确认转为插画/资产图路线。
- 工具单次时长、分辨率、次数上限以当前可用能力为准，编排时按上限拆镜，不假设能一次生成长片。

## 交接
素材齐套后输出资产+镜头清单（镜号 → 文件 → 状态），ffmpeg-post 按此清单组装；缺镜不静默跳过。
