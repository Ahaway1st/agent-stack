# storyboard-prompt

> v0.1 骨架版：本 skill 目前是占位实现，定义触发条件与工作步骤；具体内容按 PRD 第 4.2 节的搭配逻辑迭代填充。

## 做什么
把制作单拆成分镜与生成提示词，明确每段的画面、声音、字幕衔接。触发：生成之前。

## 步骤
1. 先确认当前任务确实命中上面的触发条件；不命中就不要加载本 skill 的后续上下文。
2. 按本 skill 的职责边界执行，只产出本阶段负责的交付物，并明确交给下一阶段的输入。
3. 结束时用一句话报告：做了什么、产出在哪、还缺什么。
