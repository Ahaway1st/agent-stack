# ffmpeg-post

## 流程
1. **预检**：逐个素材查规格（分辨率、帧率、编码、时长、音轨）——用 ffprobe，不靠文件名猜。规格不一先统一再拼接。
2. **组装**：按分镜表顺序拼接；转场按分镜表执行，没有写明的用硬切，不自行加花哨转场。
3. **字幕**：字幕文本以分镜表/确认过的文案为准，烧入或软字幕按交付要求；双语字幕主次分明，不遮挡主体。生成后抽帧检查字幕不溢出、不错行。
4. **声音**：音乐、音效、旁白按分镜表时间点对齐；做响度统一，避免忽大忽小；结尾淡出按制作单要求。
5. **质检（交付前必做）**：
   - 完整播放/抽帧检查：开头、每镜衔接处、结尾各查一次
   - 时长、分辨率、帧率与制作单一致
   - 无黑帧、无静音段（除非分镜表要求）、字幕与声音同步
   - 文件可播放且大小合理
6. **交付**：输出最终文件 + 一行说明（规格、时长、与制作单的差异项）。质检不过不交付，先修再检。

## 纪律
- 所有处理用可复现的命令行完成并记录命令，同一片子重做时结果一致；不靠 GUI 手工操作。
- 中间产物与最终产物分目录存放，最终文件命名含项目名与版本。
