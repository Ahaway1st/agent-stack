# cost-visibility

## 成本账本
与 TASK-STATE.md 放在一起（或独立 `COST.md`），每个阶段一行：

    | 阶段 | 主要消耗（token/子代理/生成调用） | 重试 | 备注 |
    |---|---|---|---|

## 纪律
1. **能测才写数**：数字来自工具回执或平台统计；测不到的写“未计量”，不估算冒充实测。
2. **分开记三类成本**：模型 token、子代理/并行任务、外部生成调用（按次计费的那种）——它们的计价方式不同，混在一起没有管理价值。
3. **重试单独计数**：同一动作失败重试超过 2 次，先停下来报告原因和备选路线，不默默烧掉预算。
4. **阶段汇报带成本行**：向用户汇报进度时，附一行当前累计与剩余风险（如“视频生成还剩 2 次调用额度未用”——仅当确有额度数据时）。
5. **预算是用户设的才算数**：用户没给预算时只记录和提示异常，不自行设限或拒绝执行。

## 产出
任务结束时用账本给出总账：总消耗、哪一阶段最贵、哪次重试本可避免。这是套装迭代时判断“哪个 skill 在烧钱”的唯一依据。
